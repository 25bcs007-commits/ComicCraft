# 06. Project Testing

## Project Name
ComicCraft - AI Comic Story Creator using Gemini Models

## Testing Objectives
- Check whether the application accepts user input correctly.
- Check whether Gemini AI generates the expected story.
- Check character generation.
- Check scene generation.
- Check dialogue generation.
- Check the final comic output.
- Identify and fix errors.

## Test Cases

### Test Case 1
Input: A simple adventure story idea
Expected Result: AI generates an adventure comic story.

### Test Case 2
Input: A story with two characters
Expected Result: AI generates characters and dialogues.

### Test Case 3
Input: A short story prompt
Expected Result: AI generates a complete comic-style output.

## Final Testing
The complete application should be tested before the final demonstration.
